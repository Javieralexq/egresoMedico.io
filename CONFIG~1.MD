# Configuración Supabase para Producción

## PASO 1: Crear Cuenta Supabase
1. Ve a https://supabase.com
2. Haz clic en "Sign Up"
3. Registrate con email o GitHub
4. Verifica tu correo

## PASO 2: Crear Proyecto
1. En el dashboard, haz clic en "New Project"
2. Nombre: `pacientes-form`
3. Contraseña fuerte (guárdala)
4. Región: elegir la más cercana a ti
5. Click "Create new project" (espera 2-3 minutos)

## PASO 3: Crear Tabla "pacientes"
1. En el menú izquierdo, ve a **SQL Editor**
2. Haz clic en "New Query"
3. Copia y pega esto:

```sql
CREATE TABLE pacientes (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  numero INT,
  nombre TEXT NOT NULL,
  edad TEXT,
  hcl TEXT,
  dni TEXT,
  fi DATE,
  alta DATE,
  telemonitoreo DATE,
  hb DECIMAL,
  distrito TEXT,
  direccion TEXT,
  telefono1 TEXT,
  telefono2 TEXT,
  dni_mama TEXT,
  dx1 TEXT,
  dx2 TEXT,
  dx3 TEXT,
  fecha_registro TIMESTAMP DEFAULT NOW()
);
```

4. Haz clic en "Run" (triángulo verde)

## PASO 4: Obtener Credenciales
1. Ve a **Settings** (icono de engranaje abajo a la izquierda)
2. Haz clic en **API**
3. Copia:
   - **Project URL** (ej: https://xyzxyzxyz.supabase.co)
   - **anon key** (la key pública, debajo de Project API keys)

## PASO 5: Actualizar el Formulario
Reemplaza `SUPABASE_URL` y `SUPABASE_KEY` en el archivo `patient_form_production.html` con tus credenciales.

## PASO 6: Desplegar (Hosting Gratis)
### Opción A: Vercel (Recomendado)
1. Ve a https://vercel.com
2. "Sign up" con GitHub
3. Crea repositorio en GitHub
4. Sube los archivos
5. Conecta el repo a Vercel
6. Deploy automático

### Opción B: Netlify
1. Ve a https://netlify.com
2. Arrastra tu carpeta con el HTML
3. Listo, ya tiene URL pública

### Opción C: Tu servidor propio
1. Sube el archivo HTML a tu servidor
2. Configura HTTPS
3. Las llamadas a Supabase funcionan desde cualquier lugar

## PASO 7: Descargar Datos
El botón "Descargar Excel" automáticamente:
- Lee los datos de Supabase
- Genera el archivo Excel
- Lo descarga en tu computadora

## NOTAS DE SEGURIDAD
⚠️ Las credenciales públicas (anon key) solo funcionan con RLS habilitado.
Para mayor seguridad en producción, habilita **Row Level Security (RLS)**:
1. Ve a **Authentication** → **Policies**
2. Click en la tabla "pacientes"
3. Habilita RLS
4. Crea políticas según necesites
